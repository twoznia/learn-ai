# Learn AI with Claude · Naucz się AI z Claude

A hands-on beginner course that teaches you how to **use AI powered by Claude** — from your first browser chat to writing code in Python, PowerShell, VS Code and the command line. Windows-focused, ~10 minutes per lesson.

Praktyczny kurs dla początkujących, który uczy, jak **używać AI opartego na Claude** — od pierwszej rozmowy w przeglądarce po pisanie kodu w Pythonie, PowerShell, VS Code i wierszu poleceń. Pod Windows, ~10 minut na lekcję.
