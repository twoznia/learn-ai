# A3 — Canvas & Advanced Data Analysis

⏱️ **15 minutes** · Track: 🅰️ Power User · Needs: ChatGPT (features vary by plan)

## 🧠 Theory (4 min)

Beyond chat, ChatGPT has two power features that make you dramatically more productive — no code required:

- **Canvas** — an interactive workspace where ChatGPT drafts a **document or code** you can edit side-by-side and refine, instead of scrolling a chat.
- **Advanced Data Analysis** — you upload a spreadsheet/CSV and ChatGPT **writes and runs Python** behind the scenes to clean, analyze, and chart it — then explains the results in plain English.

Both may depend on your plan/rollout. If one isn't available, the *skills* still transfer.

---

## 🛠️ Practice (9 min)

### Part 1 — Canvas

1. Start a task that produces a **document or code**, and open it in **Canvas** (look for the Canvas option when a long draft appears):

```text
Draft a one-page project proposal for a community garden. Open it in Canvas so I can edit it.
```

2. In Canvas, edit directly and ask for targeted changes:

```text
Make the budget section a table. Shorten the intro to 3 sentences. Add a timeline.
```

3. Notice you're **iterating on a living document**, not re-reading a chat. Far better for anything you'll ship.

### Part 2 — Advanced Data Analysis

1. Find or make a small CSV. No data? Ask ChatGPT: *"Make me a sample CSV of 20 rows of fake monthly sales and give me the file."*
2. Upload the CSV (📎) and ask it to analyze:

```text
Analyze this sales data. Show total and average by month, highlight the best and
worst month, and make a simple line chart. Explain what stands out in plain English.
```

3. ChatGPT writes and runs Python, then shows a **chart** and a summary. You can download the chart or the cleaned data.
4. Iterate:

```text
Now add a 3-month moving average line, and export the result as a new CSV I can download.
```

### Part 3 — Combine them

The power workflow: **analyze the data → write it up in Canvas**.

```text
Take the analysis above and turn it into a one-page report in Canvas, with the chart,
a "key findings" box, and 3 recommendations.
```

Data analysis finds the story; Canvas shapes it into a deliverable.

---

## 🧭 When to use which

| Feature | Use for |
|---------|---------|
| **Canvas** | Documents/code you'll edit and keep |
| **Advanced Data Analysis** | Spreadsheets, charts, "what does this data say" |
| **Both** | Analysis → polished report |
| Plain chat | Quick questions, drafts, brainstorming |

> ⚠️ Advanced Data Analysis can still make mistakes — sanity-check numbers and ask it to show its steps for anything important.

---

## ✅ Checkpoint

- [ ] You drafted and iterated on something in Canvas.
- [ ] You uploaded data and got an analysis + chart from Advanced Data Analysis.
- [ ] You combined analysis into a Canvas report.

---

## 🎯 Homework

Take a real spreadsheet from your life (a budget, a log, exported data). Analyze it with ChatGPT, then turn the result into a one-page report in Canvas you'd actually share.

---

## 💡 Key takeaways

- **Canvas** lets you iterate on a living document/code instead of scrolling chat.
- **Advanced Data Analysis** writes+runs Python on your data and explains the results.
- The strongest workflow is **Analyze → Canvas** for a polished report.
