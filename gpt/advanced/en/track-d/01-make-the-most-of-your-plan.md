## 🧠 Theory (5 min)

There are **two different ways to pay for GPT**, and mixing them up is the most common beginner mistake:

| | **Subscription (ChatGPT Plus / Pro)** | **API (pay-per-token)** |
|---|---|---|
| What it is | A plan for **chatgpt.com**, the desktop app, and Codex | A **developer** service billed per token |
| You pay | A **fixed monthly price** (Free tier exists) | For **every** request |
| Best for | Chatting, Custom GPTs, Deep Research, Canvas, everyday Codex | Building your own apps that call GPT |
| Extra cost per use? | **No** — included in your plan | **Yes** — each call costs money |

This whole track uses the **subscription** — no API key required. Everything you do is covered by your plan.

### The plans

- **Free** — try ChatGPT, daily limits, the everyday model.
- **Plus** — a monthly plan: much higher limits, access to the most capable models, **Deep Research**, **Canvas**, **Advanced Data Analysis**, **Custom GPTs**, image generation, and Codex usage.
- **Pro** — the highest limits and earliest access to the newest features (extended reasoning, video generation). Best if you hit Plus's limits or use Codex heavily.

> 💡 The **API** (a key from the OpenAI Platform) is a *separate*, developer path that costs extra per request. If a tutorial says "get an API key and add a payment method," that's not needed for anything in this track.

## 🛠️ Practice (9 min)

### Step 1 — Find your plan

Open [chatgpt.com](https://chatgpt.com) → your profile (bottom-left) → **Settings** (or the plan badge). Note whether you're on Free, Plus, or Pro.

### Step 2 — Tour what your plan unlocks

In ChatGPT, find these (availability depends on plan):

- The **model picker** (top of the chat) — a fast everyday model and a more-capable "thinking" model.
- **Custom GPTs / GPTs** and **Projects** (sidebar) — reusable assistants and workspaces (Track A1).
- The **tools menu** under the message box — Deep Research, Canvas, image, connectors.

Just locate them for now — the rest of this track uses each.

### Step 3 — Pick the right model for the job

Open the **model picker** and read the descriptions. The rule of thumb:

| Model | Use it for |
|-------|-----------|
| **Fast / everyday** | Quick questions, routine tasks — fast and efficient |
| **Thinking / most capable** | Hard reasoning, big documents, careful analysis |

> Exact model names in the picker change over time (and there's often an **Auto** option that chooses for you). The pattern holds: a **fast** everyday model and a **more-capable** one for hard work.

Choosing the fast model when you don't need the heaviest one makes your usage last longer (more in D3).

### Step 4 — Try the desktop app

Install the **ChatGPT desktop app** (Windows) for a quick keyboard shortcut to ChatGPT from anywhere, plus screenshot/attachment handling. Same plan, faster access — no API.

### Step 5 — Decide: do you actually need the API?

- **Chatting/working with GPT for yourself?** → Subscription. Done.
- **Building an app that calls GPT for other people?** → API (Tracks B and C cover it — a separate, metered path).

For this track: **stay on the subscription.**

## 🧩 Subscription vs API — quick decision

| You want to… | Use |
|--------------|-----|
| Chat, research, write, analyze files | Subscription |
| Use Custom GPTs, Deep Research, Canvas | Subscription |
| Use Codex on your own machine | Subscription |
| Ship an app that calls GPT for users | API |

## 🎯 Homework

Open Settings and read how your limits work. Run the same question on the **fast** and the **thinking** model and compare speed vs depth. Decide which you'll make your default (or leave it on **Auto**).

---

## 💡 Key takeaways

- The **subscription** (Plus/Pro) is a flat price with **no per-use cost**; the **API** is a separate, metered developer path.
- Your plan already includes Custom GPTs, Deep Research, Canvas, and Codex — this track uses them without an API key.
- Match the **model** to the task; the fast model when you can afford it stretches your usage.
