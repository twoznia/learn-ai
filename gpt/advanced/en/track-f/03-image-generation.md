# F3 — Image Generation

⏱️ **15 minutes** · Track: 🅵 Beyond Chat · Needs: a ChatGPT account (limits vary by plan)

## 🧠 Theory (4 min)

ChatGPT can **create and edit images** from a description — right in the chat. Great for illustrations, mockups, social posts, diagrams, and concept art.

The skill is the same as prompting for text: **be specific** — subject, style, mood, composition, colors — and **iterate**. Two extra powers worth knowing:

- **Edit, don't restart.** Ask for changes to an image you just made ("same, but at night") and it revises it.
- **Use your own images.** Upload a photo and ask ChatGPT to restyle, extend, or combine it.

> Image generation limits depend on your plan, and behavior evolves over time. The prompting skills transfer regardless.

---

## 🛠️ Practice (10 min)

### Step 1 — Generate an image

Ask for a picture with real detail:

```text
Create an image: a cozy reading nook by a rainy window, warm lamplight,
a cat asleep on a stack of books, soft watercolor style, muted autumn colors.
```

Notice how much the **specifics** (style, light, mood) shape the result.

### Step 2 — Edit like a director

Don't accept the first take — refine the same image:

```text
Same scene, but make it evening, add a steaming mug on the windowsill,
and a warmer color palette.
```

Subject, lighting, palette, framing are all yours to adjust.

### Step 3 — Use images for real tasks

```text
Make 3 simple icon-style images for a to-do app: "add task", "done", "reminder".
Flat, single color, clean lines, transparent-looking background.
```

Concept art, mockups, social graphics, slide visuals — all describable.

### Step 4 — Work from your own photo

Upload an image, then:

```text
Restyle this photo as a clean line drawing suitable for a coloring page.
```

### Step 5 — Prompt like a pro

A strong image prompt names:
- **Subject** — what's in it.
- **Style** — watercolor, photo, flat icon, 3D…
- **Mood/light** — warm, moody, bright.
- **Composition** — close-up, wide, centered.
- **Details** — colors, era, extras.

### Step 6 — Use responsibly

> ⚠️ Generated images can mislead if presented as real. Don't create images that impersonate real people, fabricate events, or could deceive. Respect likeness and copyright, and label AI-generated images when you share them.

## 🧩 Image prompt recipe

| Part | Example |
|------|---------|
| Subject | "a paper airplane" |
| Style | "soft watercolor" / "photorealistic" |
| Mood / light | "warm evening light" |
| Composition | "wide shot, centered" |
| Details | "muted autumn colors" |

---

## ✅ Checkpoint

- [ ] You generated an image with a specific, detailed prompt.
- [ ] You edited it (changed light/mood/palette) instead of restarting.
- [ ] You made images for a real use (icons, mockup, graphic).
- [ ] You restyled one of your own photos, and you know the responsible-use rules.

---

## 🎯 Homework

Create a small set of images for something real you're doing (a slide, a post, an app mockup). Edit each at least once. Write down the prompt recipe that worked so you can reuse it.

---

## 💡 Key takeaways

- ChatGPT **creates and edits images** from a description — and can restyle **your own photos**.
- **Be specific** (subject, style, mood, composition, details) and **edit like a director** instead of restarting.
- Use generated images **responsibly** — no impersonation or deception; respect likeness/copyright and label them.
