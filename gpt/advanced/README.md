## The three tracks · Trzy ścieżki

- **🅰️ Power User** — Custom GPTs, a real prompt library, Canvas & Advanced Data Analysis.
- **🅱️ Builder** — multi-turn chats, streaming, and a small app with the `openai` SDK.
- **🅲 Automator** — scheduled scripts, batch pipelines, and multi-file projects with the Codex CLI.

- **🅰️ Zaawansowany użytkownik** — Własne GPT, prawdziwa biblioteka promptów, Canvas i Zaawansowana analiza danych.
- **🅱️ Budowniczy** — czaty wieloturowe, streaming i mała aplikacja z SDK `openai`.
- **🅲 Automatyzator** — skrypty zaplanowane, potoki wsadowe i projekty wielo-plikowe z Codex CLI.
