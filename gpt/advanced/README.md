## The seven tracks · Siedem ścieżek

- **🅰️ Power User** — Custom GPTs, a real prompt library, Canvas & Advanced Data Analysis.
- **🅱️ Builder** — multi-turn chats, streaming, and a small app with the `openai` SDK.
- **🅲 Automator** — scheduled scripts, batch pipelines, and multi-file projects with the Codex CLI.
- **🅳 Subscription Power** — get the most from your ChatGPT Plus/Pro plan (no API): context, usage, personalization, agents.
- **🅴 Tools & MCP** — a full MCP training: GitHub, Atlassian, and Azure servers, and building your own with tools.
- **🅵 Beyond Chat** — Deep Research, connectors, image generation, Sora video, and Advanced Voice.
- **🅶 Codex CLI in Depth** — AGENTS.md, approval modes & sandbox, config & prompts, safe git editing, and headless mode.

- **🅰️ Zaawansowany użytkownik** — Własne GPT, prawdziwa biblioteka promptów, Canvas i Zaawansowana analiza danych.
- **🅱️ Budowniczy** — czaty wieloturowe, streaming i mała aplikacja z SDK `openai`.
- **🅲 Automatyzator** — skrypty zaplanowane, potoki wsadowe i projekty wielo-plikowe z Codex CLI.
- **🅳 Moc abonamentu** — wyciśnij maksimum z planu ChatGPT Plus/Pro (bez API): kontekst, użycie, personalizacja, agenci.
- **🅴 Narzędzia i MCP** — pełne szkolenie z MCP: serwery GitHub, Atlassian i Azure oraz budowa własnego z narzędziami.
- **🅵 Poza czatem** — Deep Research, konektory, generowanie obrazów, wideo Sora i Zaawansowany głos.
- **🅶 Codex CLI w głąb** — AGENTS.md, tryby zatwierdzania i sandbox, konfiguracja i prompty, bezpieczna edycja z git i tryb bezobsługowy.
