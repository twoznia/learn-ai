# ChatGPT zaawansowany — siedem pogłębionych ścieżek

🌐 **Język:** [English](../en/README.md) · **Polski** · [↩ Strona zaawansowana](../README.md) · [↩ Kurs podstawowy](../../pl/README.md) · [↩ Wszystkie kursy](../../../README.md)

Ukończyłeś kurs podstawowy. Ten kurs zaawansowany zaczyna od **trzech kierunków rozwoju z Lekcji 18** (Ścieżki A–C) i dodaje **cztery głębsze ścieżki (D–G)** o wyciskaniu maksimum z abonamentu, narzędziach i MCP, funkcjach mocy ChatGPT oraz Codex CLI. Pod Windows, gotowy do skopiowania kod, ~15 minut na lekcję.

> **Wymóg wstępny:** [kurs podstawowy](../pl/README.md). Ścieżki zakładają, że masz ChatGPT, klucz API (`OPENAI_API_KEY`), Pythona + `openai` oraz Node.js.
