# D1 — Wykorzystaj w pełni swój plan ChatGPT (Plus / Pro)

## 🧠 Teoria (5 min)

Są **dwa różne sposoby płacenia za GPT** i ich mylenie to najczęstszy błąd początkującego:

| | **Abonament (ChatGPT Plus / Pro)** | **API (płatność za tokeny)** |
|---|---|---|
| Co to jest | Plan dla **chatgpt.com**, aplikacji desktop i Codeksa | Usługa **deweloperska** rozliczana za tokeny |
| Płacisz | **Stałą cenę miesięczną** (jest darmowy poziom) | Za **każde** zapytanie |
| Najlepsze do | Czatowanie, Custom GPT, Deep Research, Canvas, codzienny Codex | Budowa własnych aplikacji wywołujących GPT |
| Dodatkowy koszt za użycie? | **Nie** — wliczone w plan | **Tak** — każde wywołanie kosztuje |

Cała ta ścieżka korzysta z **abonamentu** — bez klucza API. Wszystko, co robisz, pokrywa Twój plan.

### Plany

- **Free** — wypróbuj ChatGPT, dzienne limity, codzienny model.
- **Plus** — plan miesięczny: dużo wyższe limity, dostęp do najzdolniejszych modeli, **Deep Research**, **Canvas**, **Zaawansowana analiza danych**, **Custom GPT**, generowanie obrazów i korzystanie z Codeksa.
- **Pro** — najwyższe limity i najwcześniejszy dostęp do nowości (wydłużone rozumowanie, generowanie wideo). Najlepszy, jeśli osiągasz limity Plusa lub intensywnie używasz Codeksa.

> 💡 **API** (klucz z OpenAI Platform) to *osobna*, deweloperska ścieżka, która kosztuje dodatkowo za każde zapytanie. Jeśli poradnik mówi „zdobądź klucz API i dodaj metodę płatności", to nie jest potrzebne do niczego w tej ścieżce.

## 🛠️ Praktyka (9 min)

### Krok 1 — Znajdź swój plan

Otwórz [chatgpt.com](https://chatgpt.com) → Twój profil (lewy dół) → **Ustawienia** (lub odznaka planu). Sprawdź, czy masz Free, Plus czy Pro.

### Krok 2 — Zwiedź, co odblokowuje Twój plan

W ChatGPT znajdź (dostępność zależy od planu):

- **Wybór modelu** (góra czatu) — szybki codzienny model i zdolniejszy model „myślący".
- **Custom GPT / GPTs** i **Projekty** (pasek boczny) — wielokrotnego użytku asystenci i przestrzenie robocze (A1).
- **Menu narzędzi** pod polem wiadomości — Deep Research, Canvas, obraz, konektory.

Na razie po prostu je zlokalizuj — reszta ścieżki używa każdego z nich.

### Krok 3 — Dobierz właściwy model do zadania

Otwórz **wybór modelu** i przeczytaj opisy. Zasada:

| Model | Używaj do |
|-------|-----------|
| **Szybki / codzienny** | Szybkie pytania, rutynowe zadania — szybko i oszczędnie |
| **Myślący / najzdolniejszy** | Trudne rozumowanie, duże dokumenty, staranna analiza |

> Dokładne nazwy modeli w liście zmieniają się z czasem (często jest też opcja **Auto**, która wybiera za Ciebie). Schemat pozostaje: **szybki** codzienny model i **zdolniejszy** do trudnej pracy.

Wybór szybkiego modelu, gdy nie potrzebujesz najcięższego, sprawia, że Twoje użycie starcza dłużej (więcej w D3).

### Krok 4 — Wypróbuj aplikację desktop

Zainstaluj **aplikację desktop ChatGPT** (Windows) dla szybkiego skrótu klawiszowego do ChatGPT z dowolnego miejsca oraz obsługi zrzutów ekranu/załączników. Ten sam plan, szybszy dostęp — bez API.

### Krok 5 — Zdecyduj: czy naprawdę potrzebujesz API?

- **Czatujesz/pracujesz z GPT dla siebie?** → Abonament. Gotowe.
- **Budujesz aplikację wywołującą GPT dla innych?** → API (Ścieżki B i C to omawiają — osobna, licznikowa droga).

W tej ścieżce: **zostań przy abonamencie.**

## 🧩 Abonament vs API — szybka decyzja

| Chcesz… | Użyj |
|--------------|-----|
| Czatować, badać, pisać, analizować pliki | Abonament |
| Używać Custom GPT, Deep Research, Canvas | Abonament |
| Używać Codeksa na własnej maszynie | Abonament |
| Wypuścić aplikację wywołującą GPT dla użytkowników | API |

## ✅ Sprawdzian

- [ ] Wiesz, jaki masz plan (Free / Plus / Pro).
- [ ] Umiesz wyjaśnić różnicę między **abonamentem** a **API**.
- [ ] Znalazłeś/aś wybór modelu i wiesz, kiedy użyć szybkiego, a kiedy myślącego.
- [ ] Zainstalowałeś/aś lub zlokalizowałeś/aś aplikację desktop.

## 🎯 Praca domowa

Otwórz Ustawienia i przeczytaj, jak działają Twoje limity. Zadaj to samo pytanie **szybkiemu** i **myślącemu** modelowi i porównaj szybkość z głębią. Zdecyduj, który ustawisz jako domyślny (lub zostaw **Auto**).

---

## 💡 Najważniejsze wnioski

- **Abonament** (Plus/Pro) to stała cena bez kosztu za użycie; **API** to osobna, licznikowa droga deweloperska.
- Twój plan już zawiera Custom GPT, Deep Research, Canvas i Codex — ta ścieżka używa ich bez klucza API.
- Dopasuj **model** do zadania; szybki model, gdy możesz sobie pozwolić, rozciąga Twoje użycie.
