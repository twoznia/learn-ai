# Learn AI with ChatGPT · Naucz się AI z ChatGPT

[↩ All courses · Wszystkie kursy](../README.md)

A hands-on beginner course that teaches you how to **use AI powered by OpenAI's GPT models (ChatGPT)** — from your first browser chat to writing code in Python, PowerShell, VS Code and the command line. Windows-focused, ~10 minutes per lesson.

Praktyczny kurs dla początkujących, który uczy, jak **używać AI opartego na modelach GPT od OpenAI (ChatGPT)** — od pierwszej rozmowy w przeglądarce po pisanie kodu w Pythonie, PowerShell, VS Code i wierszu poleceń. Pod Windows, ~10 minut na lekcję.
