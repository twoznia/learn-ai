# D4 — Personalization & Saved Info

⏱️ **15 minutes** · Track: 🅳 Subscription Power · Needs: a Google account (Pro recommended)

## 🧠 Theory (4 min)

You can make **every** Gemini chat feel tailored — without repeating yourself — using a few built-in controls:

- **Saved info / personalization** — facts you tell Gemini once (how you work, your preferences) that it applies going forward, so you stop re-explaining.
- **Custom instructions** — a standing "how to respond to me" (tone, length, format).
- **Gems vs personalization** — a **Gem** is a specialized assistant for one job (Track A1); **personalization** is your global default across all chats. Use both.

> Availability and exact names of memory/personalization features vary by plan and roll out over time. If you don't see "saved info," the **custom-instruction** and **Gem** parts still apply fully.

---

## 🛠️ Practice (10 min)

### Step 1 — Set your personalization / custom instructions

In the Gemini app → **Settings → Personalization / Saved info** (naming varies). Add standing facts and preferences, e.g.:

```text
I'm on Windows. Keep answers concise and lead with the answer. When I ask for
steps, number them. I work in marketing, so use plain language over jargon.
```

Now chats start with *your* defaults — no re-explaining every time.

### Step 2 — Add a few useful facts

Give it context it can reuse:

```text
Remember: my team uses Google Workspace, I prefer metric units, and I like
short bullet summaries at the end of long answers.
```

Check that later chats reflect these without you repeating them.

### Step 3 — Steer tone on the fly too

Even without saved settings, shape any single answer:

```text
Rewrite that as three tight bullets a busy manager can skim.
```

Length and tone are yours to set — and this also saves usage (D3).

### Step 4 — Know when to use a Gem vs personalization

| Need | Use |
|------|-----|
| A global "how to talk to me" | Personalization / custom instructions |
| A specialist for one recurring job | A **Gem** (Track A1) |
| Facts Gemini should just know about you | Saved info |

Build a Gem for "customer emails"; set personalization for your overall voice. They stack.

### Step 5 — Review and prune

Saved info persists across chats, so keep it clean:
- **Remove** anything stale or wrong.
- Don't let it hold **secrets** or sensitive personal data.
- Know how to **turn it off** for a private, one-off chat.

> ⚠️ Personalization shapes every answer. Review what's stored occasionally, and clear anything you wouldn't want influencing future chats.

---

## 🧩 Tailoring controls

| Control | Use it to |
|---------|-----------|
| Personalization / custom instructions | Set your global voice & format |
| Saved info | Stop re-explaining your context |
| Gems | A specialist for one recurring task |
| On-the-fly steering | Shape a single answer |

---

## ✅ Checkpoint

- [ ] You set personalization / custom instructions and saw an answer change.
- [ ] You added a saved fact (or steered tone if saved info isn't available).
- [ ] You can explain when to use a Gem vs global personalization.
- [ ] You reviewed what's stored and know how to prune/disable it.

---

## 🎯 Homework

Write a short custom-instruction that captures how you like answers (length, tone, format). Add two saved facts about how you work. Then build (or reuse) one Gem for a recurring task and notice how personalization + the Gem combine.

---

## 💡 Key takeaways

- **Personalization / saved info** makes Gemini apply your preferences by default — stop re-explaining (review and prune it).
- **Custom instructions** set your global voice; **Gems** are specialists for one job — use both together.
- Keep saved info **clean and secret-free**, and know how to disable it for private chats.
