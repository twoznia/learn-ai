# Learn AI with Gemini — 10-Minute Lessons for Windows

🌐 **Language:** **English** · [Polski](../pl/README.md) · [↩ Course landing](../README.md) · [↩ All courses](../../README.md)

A hands-on beginner course that teaches you how to **use AI powered by Google Gemini** — from your very first chat in the browser to writing code that talks to Gemini from Python, PowerShell, VS Code, and the command line.

Every lesson is designed to take about **10 minutes**. Each one has:

- 🧠 **Theory** — the idea, explained simply
- 🛠️ **Practice** — click-by-click or copy-paste steps you do on your own **Windows** PC
- ✅ **Checkpoint** — how to know it worked
- 🎯 **Homework** — a tiny task to lock it in

No prior coding experience needed. We install everything together, step by step. A big plus with Gemini: **Google AI Studio has a free tier**, so you can do most of this course without spending anything.

---

## How to use this course

1. Read the lessons **in order** — each builds on the last.
2. Do the **Practice** section on your own PC. Reading isn't enough; you learn AI by using it.
3. All code blocks are ready to **copy and paste**. Look for the copy button in the corner of each code block on GitHub.
4. Stuck? Ask Gemini! Paste your error message in and ask "what does this mean and how do I fix it on Windows?"

## Quick glossary (bookmark this)

| Term | Meaning in one line |
|------|---------------------|
| **LLM** | Large Language Model — the "brain" that predicts text, like Gemini |
| **Prompt** | The message/instructions you give the AI |
| **Token** | A chunk of text (~¾ of a word). AI cost and limits are measured in tokens |
| **API** | A way for your code to talk to Gemini over the internet |
| **API key** | A secret password that identifies your code to Google |
| **Model** | A specific version of Gemini (e.g. Pro, Flash, Flash-Lite) |
| **Context window** | How much text Gemini can "see" at once (Gemini's is very large) |
| **Multimodal** | Understands text, images, audio and more in one model |
| **Grounding** | Connecting answers to live sources like Google Search |
| **Hallucination** | When AI states something wrong as if it were true |
