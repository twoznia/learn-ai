# GitHub Copilot + VS Code — Hands-On Lessons for Windows

🌐 **Language:** **English** · [Polski](../pl/README.md) · [↩ Course landing](../README.md) · [↩ All courses](../../README.md)

A hands-on course that teaches you to **actually use GitHub Copilot** with VS Code and GitHub — from your first AI code completion to automatic PR reviews, generated READMEs, and delegating whole tasks to Copilot's coding agent. Windows-focused, copy-ready steps, ~10–13 minutes per lesson.

Every lesson has:

- 🧠 **Theory** — the idea, explained simply
- 🛠️ **Practice** — click-by-click / copy-paste steps on your **Windows** PC
- ✅ **Checkpoint** — how to know it worked
- 🎯 **Homework** — a tiny task to lock it in
- 💡 **Key takeaways**

It starts easy and gets progressively deeper — no prior Copilot or GitHub experience needed. We install everything together.

---

## How to use this course

1. Do the lessons **in order** — each builds on the last.
2. Actually do the **Practice** on your own PC. You learn Copilot by using it.
3. All commands are ready to **copy and paste**.
4. Stuck? Ask Copilot! Paste your error and ask "what does this mean and how do I fix it on Windows?"

## Quick glossary (bookmark this)

| Term | Meaning in one line |
|------|---------------------|
| **Completion** | The grey "ghost text" Copilot suggests as you type |
| **Copilot Chat** | Talking to Copilot about your code (view or inline) |
| **Edit / Agent mode** | Multi-file edits; goal-driven changes |
| **Repo** | A project tracked by Git and hosted on GitHub |
| **Commit** | A saved snapshot of your changes |
| **Branch** | A parallel copy of the code for safe changes |
| **Pull request (PR)** | A proposal to merge a branch, with review |
| **CI** | Automation that runs your tests on every PR |
| **Coding agent** | Copilot working from an issue to open a PR |
