## 🧠 Theory (4 min)

**GitHub Copilot** is an AI assistant for writing code and working with software projects. Think of it as a **pair programmer** that lives inside your editor and on GitHub: it suggests code as you type, answers questions in a chat, edits files for you, writes tests and docs, and even helps review pull requests.

It shows up in several places — and this course uses all of them:

- **In VS Code** — the main event: completions, chat, and multi-file edits.
- **On github.com** — chat about a repo, summarize pull requests, review changes.
- **In the terminal & CI** — the Copilot CLI and automated checks.

Under the hood it's powered by large language models (you can often **pick the model** in the UI). You don't need to know how they work — you need to know how to *drive* them well, which is what this course teaches.

### Plans (at a glance)

| Plan | Who it's for |
|------|--------------|
| **Copilot Free** | Try it — a limited monthly amount of completions and chat |
| **Copilot Pro** | Individuals who want unlimited everyday use |
| **Business / Enterprise** | Teams, with admin controls and policy |

> Students, teachers, and maintainers of popular open-source projects can often get **Copilot Pro for free** — check GitHub's current docs. Plan names, limits, and features change over time; when in doubt, check the official GitHub Copilot documentation.

## 🛠️ Practice (5 min)

### Step 1 — Get a GitHub account

Go to **https://github.com** and sign up (or sign in). Everything Copilot does is tied to this account.

### Step 2 — Look at Copilot's plans

Visit **https://github.com/features/copilot** and open the pricing/plans. Note which plan you'll start on — **Free is plenty** for this whole course's early lessons.

### Step 3 — Enable Copilot on your account

In GitHub, go to your **Settings → Copilot** (or the Copilot page it links to) and turn it on / start the Free plan. You've now got an AI pair programmer attached to your account.

### Step 4 — See where it lives

Skim these so the rest of the course feels familiar:
- The **Copilot** icon on github.com (top bar) — chat in the browser.
- The plan settings you just saw.

Next lesson we install it into VS Code and write our first AI-assisted code.

## 💡 Key takeaways

- **GitHub Copilot** is an AI pair programmer across VS Code, github.com, and the terminal.
- It does completions, chat, multi-file edits, tests/docs, and PR review — all driven by you.
- Start on **Copilot Free**; students/teachers/OSS maintainers may get Pro free. Features evolve — check the docs.
