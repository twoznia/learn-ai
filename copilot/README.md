# GitHub Copilot + VS Code · GitHub Copilot + VS Code

[↩ All courses · Wszystkie kursy](../README.md)

A hands-on course on **using GitHub Copilot** with VS Code and GitHub — from your first AI code completion to optimizing pull requests, automatic code review, generated READMEs, and Copilot's coding agent. Starts easy, gets progressively deeper. Windows-focused, ~10–13 minutes per lesson.

Praktyczny kurs o **używaniu GitHub Copilota** z VS Code i GitHubem — od pierwszego uzupełnienia kodu przez AI po optymalizację pull requestów, automatyczny przegląd kodu, generowane README i agenta kodującego Copilota. Zaczyna łatwo, stopniowo się pogłębia. Pod Windows, ~10–13 minut na lekcję.

> **No experience needed · Bez doświadczenia:** we install VS Code, Copilot, and Git together. Knowing basic Python helps but isn't required. · Instalujemy VS Code, Copilota i Git razem. Znajomość podstaw Pythona pomaga, ale nie jest wymagana.

## What's inside · Co w środku

**18 lessons across 5 parts**, easy to advanced:

1. **Foundations** — Copilot in VS Code: completions, chat, prompting.
2. **Everyday coding** — Edits & Agent mode, tests/docs/refactoring, custom instructions, context.
3. **GitHub essentials** — Git, branches & pull requests, issues & projects.
4. **Optimizing PRs, reviews & docs** — great PRs, automatic code review, READMEs, Copilot on github.com.
5. **Advanced & automation** — the coding agent, Copilot CLI, GitHub Actions/CI & Autofix.

**18 lekcji w 5 częściach**, od łatwego po zaawansowane:

1. **Podstawy** — Copilot w VS Code: uzupełnienia, czat, promptowanie.
2. **Codzienne kodowanie** — tryb Edit i Agent, testy/dokumentacja/refactoring, własne instrukcje, kontekst.
3. **Podstawy GitHuba** — Git, gałęzie i pull requesty, zgłoszenia i projekty.
4. **Optymalizacja PR-ów, przeglądów i dokumentacji** — świetne PR-y, automatyczny przegląd kodu, README, Copilot na github.com.
5. **Zaawansowane i automatyzacja** — agent kodujący, Copilot CLI, GitHub Actions/CI i Autofix.

Ten kurs dotyczy **przepływu pracy z asystentem kodowania** (Copilot + VS Code + GitHub). Kursy **Claude**, **Gemini** i **ChatGPT** w tym repo uczą **modeli AI i narzędzi czatowych** stojących za asystentami jak Copilot — zrób je, by zrozumieć, co jest pod maską.
