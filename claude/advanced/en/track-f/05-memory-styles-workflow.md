## 🧠 Theory (4 min)

The last mile of getting more from Claude isn't a big feature — it's a handful of controls that make **every** chat better:

- **Memory** — Claude remembering useful context about you/your work across conversations, so you stop re-explaining. (Rolling out on paid plans; controls live in Settings.)
- **Custom styles** — telling Claude *how* to write for you (tone, length, formatting) so output matches your voice by default.
- **Chat-workflow craft** — editing and branching conversations, regenerating, sharing, and toggling extended thinking. Small skills, big daily leverage.

Master these and Claude feels tailored instead of generic.

> Memory availability and its exact controls vary by plan and are rolling out over time. If you don't see it, the **style** and **workflow** parts of this lesson still apply fully.

## 🛠️ Practice (10 min)

### Step 1 — Set up a custom style

Open **Settings → (Personalization / Styles)** or the style selector near the message box. Create or pick a style, e.g.:

```text
Be concise and direct. Lead with the answer, then brief support. Use short
paragraphs, no filler, no "As an AI." When I ask for code, give the code first.
```

Now chats default to *your* voice. Switch styles per task (e.g. a "formal email" style vs a "quick notes" style).

### Step 2 — Try style on the fly

Even without saved styles, steer any single answer:

```text
Rewrite that as three tight bullets a busy manager can skim.
```

Length and tone are yours to set — see Track D3, this also saves tokens.

### Step 3 — Manage memory (if available)

In **Settings → Memory**, review what Claude remembers and:
- **Add** standing facts ("I work in marketing; I use Windows; keep answers Windows-first").
- **Remove** anything stale or wrong.
- Know how to **turn it off** for a private chat.

> ⚠️ Memory persists across chats. Don't let it hold secrets or sensitive personal data; review and prune it.

### Step 4 — Edit and branch a conversation

- **Edit** an earlier message and resend to change the whole downstream answer — cleaner than arguing with a bad thread.
- **Branch** by editing to explore a different direction without losing the original.
- **Regenerate** to get an alternative answer to the same prompt.

Try it: send a prompt, then **edit** it to add one constraint and resend. Notice you fixed the root instead of piling on corrections.

### Step 5 — Toggle extended thinking for hard problems

For genuinely hard reasoning (tricky logic, multi-step planning), turn on **extended thinking** so Claude works more carefully before answering. Leave it off for quick stuff — it's slower.

### Step 6 — Share a chat when useful

Use the share option to send a **read-only link** to a conversation (great for showing a colleague how you solved something).

> ⚠️ A shared chat exposes its contents. Review for private data before sharing.

## 🧩 Everyday power controls

| Control | Use it to |
|---------|-----------|
| **Custom style** | Make output match your voice by default |
| **Memory** | Stop re-explaining your context (review/prune it) |
| **Edit + resend** | Fix the root prompt, not the symptoms |
| **Branch** | Explore an alternative without losing the original |
| **Regenerate** | Get a different take on the same ask |
| **Extended thinking** | Harder reasoning on tough problems |
| **Share** | Send a read-only chat link (review first) |

## ✅ Checkpoint

- [ ] You set (or switched) a custom style and saw output change.
- [ ] You reviewed/pruned memory, or steered tone on the fly if memory isn't available.
- [ ] You **edited and resent** a message to change the outcome.
- [ ] You know when to toggle extended thinking and how to share a chat safely.

## 🎯 Homework

Create two custom styles you'll actually use (e.g. "concise answers" and "polished email"). Set one useful memory fact about how you work. Then take a messy old chat and redo it cleanly by editing the root prompt instead of adding corrections.

---

## 💡 Key takeaways

- **Custom styles** make Claude write in your voice by default; **memory** stops you re-explaining (review and prune it).
- **Edit/branch/regenerate** fix and explore at the root instead of arguing down a thread.
- **Extended thinking** for hard problems, **sharing** for showing your work — both with a privacy check.
