## 🧠 Theory (5 min)

There are **two different ways to pay for Claude**, and mixing them up is the most common beginner mistake:

| | **Subscription (Pro / Max)** | **API (pay-per-token)** |
|---|---|---|
| What it is | A monthly plan for **claude.ai**, the desktop app, and Claude Code | A **developer** service billed per token you send/receive |
| You pay | A **fixed monthly price** | For **every** request, on top of anything else |
| Best for | Chatting, Projects, Skills, connectors, everyday coding | Building your own apps that call Claude |
| Extra cost per use? | **No** — it's included in your plan | **Yes** — each call costs money |

This whole track uses the **subscription** — no API key, no per-request billing. Everything you do is already paid for by your plan.

### The three plans

- **Free** — try Claude, limited daily usage, one main model.
- **Pro** — a monthly plan: much higher usage, access to more models, **Projects**, **Skills**, **connectors (MCP)**, and **Claude Code** (limited).
- **Max** — the same features with **far higher limits** (and priority when things are busy). Two tiers (5× and 20× Pro's usage). Best if you hit Pro's limits often or use Claude Code heavily.

> 💡 The API is billed **separately** and costs extra. If a tutorial tells you to "get an API key and paste your credit card," that's the developer path — you don't need it for anything in this track.

## 🛠️ Practice (9 min)

### Step 1 — Find your plan

Open [claude.ai](https://claude.ai) → click your name/initials (bottom-left) → **Settings**. You'll see your current plan. Note whether you're on Free, Pro, or Max.

### Step 2 — Tour what your plan unlocks

In the chat window, look for these (availability depends on your plan):

- The **model selector** (top of the chat) — Sonnet, Opus, Haiku.
- **Projects** (left sidebar) — reusable workspaces with their own knowledge.
- The **attachment / tools** menu — connectors and Skills live here.
- **Search & tools** toggles under the message box.

You don't have to use them yet — just find where they are. The rest of this track visits each one.

### Step 3 — Pick the right model for the job

Click the **model selector** and read the short descriptions. The rule of thumb:

| Model | Use it for |
|-------|-----------|
| **Sonnet** | Your everyday default — fast, smart, efficient |
| **Opus** | The hardest tasks: deep reasoning, big coding jobs |
| **Haiku** | Quick, simple questions where speed matters |

Choosing a lighter model when you don't need the heaviest one makes your usage last longer (more on that in D3).

### Step 4 — Decide: do you actually need the API?

Ask yourself: *Am I chatting/working with Claude, or building software that calls Claude for other people?*

- **Chatting or coding for yourself?** → Subscription. You're done. No API.
- **Building an app that sends requests to Claude programmatically?** → That's the API path (a separate, paid, developer topic — Tracks B and C touch it).

For this track: **stay on the subscription.**

## 🧩 Subscription vs API — quick decision

| You want to… | Use |
|--------------|-----|
| Chat, research, write, analyze files | Subscription |
| Organize work in Projects | Subscription |
| Use Skills and connectors (MCP) | Subscription |
| Code with Claude Code on your own machine | Subscription |
| Ship an app that calls Claude for users | API (paid separately) |

## 🎯 Homework

Open **Settings → Usage** (or the plan page) and read how your limits work. Then run the same question on **Sonnet** and on **Opus** and notice the difference in speed and depth. Decide which model you'll make your default.

---

## 💡 Key takeaways

- The **subscription** (Pro/Max) is a flat monthly price with **no per-use cost**; the **API** is paid per token and is a separate developer path.
- Your plan already includes Projects, Skills, connectors, and Claude Code — this track uses all of them without an API key.
- Match the **model** to the task; a lighter model when you can afford it stretches your usage.
