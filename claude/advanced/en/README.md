# Advanced Claude — Three Deep-Dive Tracks

🌐 **Language:** **English** · [Polski](../pl/README.md) · [↩ Advanced landing](../README.md) · [↩ Beginner course](../en/README.md)

You finished the beginner course — you can chat, prompt, upload files, and call the API. This advanced course takes the **three growth paths from Lesson 18** and turns each into a hands-on track. Windows-focused, copy-ready code, ~15 minutes per lesson.

> **Prerequisite:** the [beginner course](../en/README.md). Tracks assume you already have Claude Desktop, an API key (`ANTHROPIC_API_KEY`), Python, and Node.js from there.

---

## 🅰️ Track A — Power User (no coding)

Get dramatically more out of Claude without writing code.

| # | Lesson | What you'll learn |
|---|--------|-------------------|
| A1 | [Projects mastery](track-a/01-projects-mastery.md) | Build a Project that works like a real teammate |
| A2 | [Build a prompt library](track-a/02-prompt-library.md) | A reusable, organized system for your best prompts |
| A3 | [Advanced MCP](track-a/03-advanced-mcp.md) | Multiple servers, real workflows, and safety |

## 🅱️ Track B — Builder (coding)

Write real Python apps on top of the Claude API.

| # | Lesson | What you'll learn |
|---|--------|-------------------|
| B1 | [Conversations with memory](track-b/01-conversations-with-memory.md) | Multi-turn chat that remembers |
| B2 | [Streaming responses](track-b/02-streaming.md) | Show replies as they're generated |
| B3 | [Build a small app](track-b/03-build-an-app.md) | A study-buddy CLI you'll actually keep |

## 🅲 Track C — Automator

Make Claude do repetitive work for you, hands-free.

| # | Lesson | What you'll learn |
|---|--------|-------------------|
| C1 | [Schedule scripts with Task Scheduler](track-c/01-schedule-with-task-scheduler.md) | A daily AI brief that runs itself |

| C3 | [Multi-file projects with Claude Code](track-c/03-multi-file-projects.md) | Plan and build bigger projects with AI |

## How to use this course

- Pick the **track** that matches your goal — you don't have to do them in order.
- Each lesson still has 🧠 Theory, 🛠️ Practice, ✅ Checkpoint, 🎯 Homework.
- Everything builds on tools you installed in the beginner course.
