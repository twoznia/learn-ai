# D1 — Wykorzystaj abonament (Pro / Max)

## 🧠 Teoria (5 min)

Są **dwa różne sposoby płacenia za Claude** i ich mylenie to najczęstszy błąd początkujących:

| | **Abonament (Pro / Max)** | **API (płatność za tokeny)** |
|---|---|---|
| Co to | Miesięczny plan dla **claude.ai**, aplikacji desktop i Claude Code | Usługa **dla programistów**, rozliczana za każdy token |
| Płacisz | **Stałą cenę miesięczną** | Za **każde** zapytanie, dodatkowo |
| Najlepsze do | Rozmów, Projektów, Skilli, konektorów, codziennego kodowania | Budowania własnych aplikacji wołających Claude |
| Dodatkowy koszt za użycie? | **Nie** — wliczony w plan | **Tak** — każde wywołanie kosztuje |

Cała ta ścieżka używa **abonamentu** — bez klucza API, bez płatności za zapytanie. Wszystko, co robisz, jest już opłacone przez Twój plan.

### Trzy plany

- **Free** — wypróbuj Claude, ograniczone dzienne użycie, jeden główny model.
- **Pro** — plan miesięczny: dużo większe użycie, dostęp do większej liczby modeli, **Projekty**, **Skille**, **konektory (MCP)** i **Claude Code** (ograniczony).
- **Max** — te same funkcje z **dużo wyższymi limitami** (i priorytetem przy obciążeniu). Dwa poziomy (5× i 20× użycia Pro). Najlepszy, jeśli często sięgasz limitów Pro lub intensywnie używasz Claude Code.

> 💡 API jest rozliczane **osobno** i kosztuje dodatkowo. Jeśli poradnik każe „wziąć klucz API i wkleić kartę”, to ścieżka programistyczna — w tej ścieżce nie jest potrzebna.

## 🛠️ Praktyka (9 min)

### Krok 1 — Sprawdź swój plan

Otwórz [claude.ai](https://claude.ai) → kliknij imię/inicjały (lewy dół) → **Settings**. Zobaczysz swój plan. Zanotuj, czy to Free, Pro czy Max.

### Krok 2 — Zwiedź, co daje Twój plan

W oknie czatu znajdź (dostępność zależy od planu):

- **Selektor modelu** (u góry czatu) — Sonnet, Opus, Haiku.
- **Projekty** (lewy pasek) — wielokrotnego użytku przestrzenie z własną wiedzą.
- Menu **załączników / narzędzi** — tu są konektory i Skille.
- Przełączniki **Search & tools** pod polem wiadomości.

Nie musisz jeszcze z nich korzystać — po prostu znajdź, gdzie są. Reszta ścieżki odwiedza każdy z nich.

### Krok 3 — Dobierz model do zadania

Kliknij **selektor modelu** i przeczytaj krótkie opisy. Zasada kciuka:

| Model | Do czego |
|-------|-----------|
| **Sonnet** | Codzienny domyślny — szybki, mądry, oszczędny |
| **Opus** | Najtrudniejsze zadania: głębokie rozumowanie, duże projekty kodu |
| **Haiku** | Szybkie, proste pytania, gdy liczy się tempo |

Wybór lżejszego modelu, gdy nie potrzebujesz najcięższego, sprawia, że użycie starcza dłużej (więcej w D3).

### Krok 4 — Zdecyduj: czy naprawdę potrzebujesz API?

Zapytaj siebie: *czy rozmawiam/pracuję z Claude, czy buduję oprogramowanie wołające Claude dla innych?*

- **Rozmawiasz lub kodujesz dla siebie?** → Abonament. Koniec. Bez API.
- **Budujesz aplikację wysyłającą zapytania do Claude programowo?** → To ścieżka API (osobny, płatny temat programistyczny — dotykają go Ścieżki B i C).

W tej ścieżce: **zostań na abonamencie.**

## 🧩 Abonament vs API — szybka decyzja

| Chcesz… | Użyj |
|--------------|-----|
| Rozmawiać, badać, pisać, analizować pliki | Abonament |
| Organizować pracę w Projektach | Abonament |
| Używać Skilli i konektorów (MCP) | Abonament |
| Kodować z Claude Code na własnym komputerze | Abonament |
| Wypuścić aplikację wołającą Claude dla użytkowników | API (płatne osobno) |

- [ ] Wiesz, na jakim planie jesteś (Free / Pro / Max).
- [ ] Umiesz wyjaśnić różnicę między **abonamentem** a **API**.
- [ ] Znalazłeś selektor modelu i wiesz, kiedy sięgnąć po Sonnet, Opus czy Haiku.

---

## 🎯 Zadanie

Otwórz **Settings → Usage** (lub stronę planu) i przeczytaj, jak działają Twoje limity. Potem zadaj to samo pytanie na **Sonnecie** i na **Opusie** i zauważ różnicę w szybkości i głębi. Zdecyduj, który model będzie Twoim domyślnym.

---

## 💡 Najważniejsze wnioski

- **Abonament** (Pro/Max) to stała cena miesięczna **bez kosztu za użycie**; **API** jest płatne za tokeny i to osobna ścieżka programistyczna.
- Twój plan już zawiera Projekty, Skille, konektory i Claude Code — ta ścieżka używa ich wszystkich bez klucza API.
- Dopasuj **model** do zadania; lżejszy model, gdy możesz, rozciąga Twoje użycie.
