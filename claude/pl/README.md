# Naucz się AI z Claude — 10-minutowe lekcje dla Windows

🌐 **Język:** [English](../en/README.md) · **Polski** · [↩ Strona główna](../README.md)

Praktyczny kurs dla początkujących, który uczy, jak **używać AI opartego na Claude** — od pierwszej rozmowy w przeglądarce po pisanie kodu rozmawiającego z Claude z poziomu Pythona, PowerShell, VS Code i wiersza poleceń.

Każda lekcja zajmuje około **10 minut**. Każda zawiera:

- 🧠 **Teorię** — pomysł wyjaśniony prostym językiem
- 🛠️ **Praktykę** — kroki krok po kroku, które wykonujesz na swoim komputerze z **Windows**
- ✅ **Sprawdzenie** — jak poznać, że się udało
- 🎯 **Zadanie** — małe ćwiczenie utrwalające

Nie potrzebujesz wcześniejszego doświadczenia w programowaniu. Wszystko instalujemy razem, krok po kroku.

---

## Jak korzystać z kursu

1. Czytaj lekcje **po kolei** — każda opiera się na poprzedniej.
2. Wykonuj sekcję **Praktyka** na własnym komputerze. Samo czytanie nie wystarczy; AI uczysz się, używając go.
3. Wszystkie bloki kodu są gotowe do **skopiowania i wklejenia**. Szukaj przycisku kopiowania w rogu bloku kodu na GitHubie.
4. Utknąłeś? Zapytaj Claude! Serio — wklej komunikat błędu do Claude i zapytaj „co to znaczy i jak to naprawić na Windows?”.

## Narzędzia, których dotkniesz

- **Claude.ai** — Claude w przeglądarce (Lekcja 2)
- **Claude Desktop** — aplikacja dla Windows (Lekcja 5)
- **Python** — najprzyjaźniejszy język programowania dla AI (Lekcja 8)
- **PowerShell** — już wbudowany w Windows (Lekcja 11)

- **Claude Code** — asystent kodowania Anthropic w wierszu poleceń (Lekcja 13)
- **MCP** — Model Context Protocol, łączy Claude z Twoimi danymi (Lekcja 15)

## Szybki słowniczek (dodaj do zakładek)

| Termin | Znaczenie w jednym zdaniu |
|------|---------------------|
| **LLM** | Duży model językowy — „mózg”, który przewiduje tekst, jak Claude |
| **Prompt** | Wiadomość/instrukcja, którą podajesz AI |
| **Token** | Kawałek tekstu (~¾ słowa). Koszt i limity AI liczy się w tokenach |
| **API** | Sposób, w jaki Twój kod rozmawia z Claude przez internet |
| **Klucz API** | Tajne hasło identyfikujące Twój kod wobec Anthropic |
| **Model** | Konkretna wersja Claude (np. Opus, Sonnet, Haiku) |
| **Okno kontekstu** | Ile tekstu Claude „widzi” naraz |
| **Halucynacja** | Gdy AI podaje coś błędnego jako prawdę |
| **MCP** | Standard pozwalający Claude bezpiecznie korzystać z zewnętrznych narzędzi i danych |
