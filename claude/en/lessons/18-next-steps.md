## 🧠 Theory: three directions to grow (3 min)

Pick the path that excites you most.

### Path A — The Power User (no coding)
Go deeper with the chat apps and Projects.
- Build **Projects** for each area of your life/work (Lesson 7).
- Create a personal **prompt library** (your `my-prompts.txt`).
- Connect more **MCP servers** to your desktop (Lesson 15).

### Path B — The Builder (coding)
Turn scripts into real tools.
- Learn **conversations with memory** (send message history back each turn).
- Add **streaming** so replies appear word-by-word.
- Build a small app: a study buddy, an email drafter, a data summarizer.

### Path C — The Automator
Make AI do repetitive work for you.
- Schedule your PowerShell script with **Task Scheduler** (e.g. a daily summary).
- Chain steps: read a file → ask Claude → save the result.
- Use **Claude Code** for bigger multi-file projects.

## 🧭 A few habits of great AI users

1. **Reach for AI first** on any word-heavy task — then refine.
2. **Iterate** — treat the first answer as a draft.
3. **Verify** anything important.
4. **Keep a prompt library** — reuse what works.
5. **Stay curious** — new capabilities ship often; try them.
