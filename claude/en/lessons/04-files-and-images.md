# Lesson 04 — Working with Files and Images

⏱️ **10 minutes** · Level: Beginner · Needs: claude.ai + any PDF/image on your PC

## 🧠 Theory (3 min)

Claude isn't limited to text you type. You can **upload files** and Claude will read them:

- **PDFs, Word docs, spreadsheets, text files** → Claude reads the content.
- **Images and screenshots** → Claude can *see* them (charts, photos, handwriting, error messages).

This is huge for beginners because you can point Claude at a real document and say "explain this" instead of retyping everything.

> ⚠️ **Privacy note:** Only upload files you're comfortable sharing with a cloud service. Don't upload passwords, other people's private data, or confidential company info you're not allowed to share. More in Lesson 17.

---

## 🛠️ Practice (6 min)

### Step 1 — Summarize a PDF

1. Find any PDF on your PC (a manual, a report, a receipt). No PDF? In Edge, open any webpage → **⋯ menu → Print → Save as PDF**.
2. In claude.ai, click the **📎 attach** icon near the message box.
3. Select your PDF.
4. Send this prompt:

```text
Summarize this document in 5 bullet points. Then list any dates, names,
or amounts I should not miss. If something is unclear, say so.
```

### Step 2 — Ask questions about the file

Same chat, follow up:
```text
What is the single most important action I need to take based on this document?
```

### Step 3 — Let Claude read a screenshot

1. Press **Windows + Shift + S** to snip part of your screen (this copies it).
2. Paste directly into the claude.ai message box with **Ctrl + V**.
3. Try:

```text
Here's a screenshot. Explain what I'm looking at and what each button does.
```

### Step 4 — The killer beginner move: debug an error

Next time **anything** on your PC shows an error message:
1. Snip it (**Windows + Shift + S**).
2. Paste into Claude with:

```text
I got this error on Windows. Explain in plain English what it means and give me
the safest steps to fix it. Assume I'm not technical.
```

This one trick will save you countless hours.

---

## 📋 What you can upload — cheat sheet

| File type | Claude can… |
|-----------|-------------|
| PDF / Word / TXT | Summarize, answer questions, extract info |
| Excel / CSV | Explain data, spot trends, suggest formulas |
| PNG / JPG screenshot | Read text in it, explain UI, decode errors |
| Photo of a document | Transcribe and summarize |
| Photo of handwriting | Read and type it up |

## 💡 Key takeaways

- 📎 Upload PDFs/docs; Claude reads them.
- **Win+Shift+S** then **Ctrl+V** pastes screenshots straight into Claude.
- Pasting error messages is the fastest way to fix computer problems.
- Never upload secrets or others' private data.
